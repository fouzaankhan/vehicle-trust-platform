# Frontend Pages

This folder contains the individual **Streamlit pages** used in the dashboard.

## Pages
- `1_Analyze_Listing.py` — predict fair market price from vehicle inputs
- `2_Market_Analytics.py` — visualize market trends and dataset insights
- `3_History.py` — view previously saved analyses
- `4_Trust_Report.py` — generate a full trust report using price, NLP, and image checks
