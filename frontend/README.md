# Frontend

This folder contains the **Streamlit frontend** for the Vehicle Trust Intelligence Platform.

## Purpose
The frontend provides the user-facing dashboard for:
- vehicle price analysis
- trust report generation
- market analytics
- analysis history viewing

## Main Files
- `main.py` — Streamlit landing page / dashboard home
- `pages/` — individual Streamlit app pages
- `utils/` — frontend helper utilities such as API communication
